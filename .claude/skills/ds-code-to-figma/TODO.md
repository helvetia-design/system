## For team discussion

Lessons from the Divider rebuild (23.11.2026), not yet in the skill. Decide per item: add to the skill, change the template / script, or drop.

- [ ] **Outdated documentation frames.** A frame cloned before a template change keeps the old sections: Divider's frame (18.11.2026) had group markers in Anatomy instead of `Anatomy/Marker` instances, and `body` / `Component Sets` were fixed width, so the 3520px set was clipped at 1029px. Fixed by hand: re-cloned the Anatomy and Measurements sections from the template, set `body` and `Component Sets` to hug. Proposal: Phases 7 and 8 always re-clone their section from the template (not only fill the placeholder), and Phase 3 re-checks the frame sizing when it resumes an older frame.
- [ ] **Hidden layers fail the numeric check.** Figma reports hidden auto-layout children as `FIXED`, even when they were set to `FILL` (Divider: the hidden `line` / `dash` layer per `dashed` variant). `figma-check-set.mjs` lists them as unbound sizes (`review`). Proposal: skip layers that are hidden without a boolean (the same rule Phase 4c already has for icons), or report them separately.
- [ ] **Props that are invisible in the set.** `space` is an outer margin: modeled as padding, it's transparent, so the 10 `space` columns look identical (Divider: 240 variants, 216 of them look like another one). Tried dropping it (24 variants) and restored it so the Figma props stay 1:1 with code. Question: rule for invisible props (outer margin, semantic-only props), keep as variant or exclude and document in Measurements only?
- [ ] **Measurements for a per-option spacing prop.** Divider shows `space` as 10 instances between Lorem ipsum lines (Desktop mode) and 10 table rows (`Space · <x>`, numbers 3–12) instead of one `Space` row. Question: make this the pattern for spacing props without a table axis?
- [ ] **Default `space=none` feels odd** (user feedback): the code default is `none`, so the top-left cell has no space. Question for code: is `none` the right default?
