## Guidelines

The shape is decorative. The host and its inner SVG are always <code>aria-hidden="true"</code>, so assistive technology ignores it. Authors do not add <code>aria-hidden</code>, and an <code>aria-label</code> would never be exposed.

<A11yGuidelines
  items={[
    {
      type: 'do',
      title: 'State meaning in text',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          If the information matters, put it in real content next to the shape. Color, variation and rotation are never announced.
        </p>
      ),
    },
    {
      type: 'do',
      title: 'Keep shapes clear of content',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          Place shapes beside text rather than behind it, so the text keeps its own contrast.
        </p>
      ),
    },
    {
      type: 'dont',
      title: 'Don\'t use a shape to convey information',
      content: (
        <p style={{ margin: '0.5rem 0 0 0' }}>
          Status, category or step belong in <code>ds-badge</code>, <code>ds-tag</code> or <code>ds-steps</code>, which expose text.
        </p>
      ),
    },
  ]}
/>
