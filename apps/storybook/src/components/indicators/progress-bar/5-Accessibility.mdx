## Guidelines

The component sets <code>role="progressbar"</code>, <code>aria-valuemin</code>, <code>aria-valuemax</code> and <code>aria-valuenow</code> itself. Authors do not add them.

## Values outside 0–100

Values below 0 or above 100 are clamped, for both the drawn width and the announced <code>aria-valuenow</code>. <code>NaN</code> counts as 0.

## Motion

The fill transition is turned off when the user prefers reduced motion.
